# 록맨 11 운명의 톱니바퀴!! 한글패치

Mega Man 11 / 록맨 11 운명의 톱니바퀴!! (Nintendo Switch, `0100B0C0086B0000`) 한글패치입니다.
게임의 **일본어(日本語) 칸**을 한국어로 바꿉니다. 다른 언어 칸은 그대로입니다(부팅 직후 안내 문구만 예외, 아래 참고).

> 게임 파일(NSP·추출물)은 이 저장소에 없습니다. 패치 파일은 [Releases](../../releases) 에서 받으세요.

> **⚠ 패치를 넣은 뒤 게임 안에서 한국어를 골라야 합니다.**
> 타이틀 → **OPTIONS → 언어 설정(Language) → 표시 언어**를 **「한국어」**로 바꾸고 **EXIT** 하세요.
> (패치 후 목록 맨 앞 「日本語」 칸이 「한국어」로 바뀌어 있습니다. 음성은 일본어·영어 중 자유롭게 고르세요.)

## 설치

### 스위치 (Atmosphere)

`Rockman11_KR_<버전>_atmosphere.zip` 을 SD 카드 루트에 풉니다 → `atmosphere/contents/0100B0C0086B0000/romfs/...`

### 에뮬레이터 (Eden / yuzu 계열, Ryujinx)

`Rockman11_KR_<버전>_emulator.zip` 을 풀면 나오는 `KoreanPatch` 폴더를 게임의 모드 폴더에 넣습니다.

- Eden / yuzu 계열: `load/0100B0C0086B0000/KoreanPatch/romfs`
- Ryujinx: `mods/contents/0100b0c0086b0000/KoreanPatch/romfs`

### xdelta

`Rockman11_KR_<버전>_xdelta.zip` 은 바뀐 arc 26개의 차분입니다. RomFS 에서 뽑은 원본 arc(`nativeNXx64/arc/...`)를
같은 상대 경로로 두고 `적용.bat` 을 실행하면 `out/` 에 한글판 arc 가 생깁니다. 원본·결과 SHA1 은 `SHA1_원본_한글판.txt`.

## 한글화 범위

- 이야기 장면 대사 전부, 대화 이름표
- 메뉴·옵션·안내 창·버튼 안내, 무기·아이템·파츠 설명, 상점(LABORATORY), 챌린지·랭킹·업적, 갤러리(보스·적 프로필)
- 그림: 타이틀 로고 부제 「운명의 톱니바퀴!!」, 보스 소개 화면의 한글 이름 8개, 시작 경고 화면(「주의」)
- 부팅 직후 「불러오는 중」 등 세이브를 읽기 전 안내 문구: 이때는 본체 언어를 따르며 한국어 본체에서는 영어 칸이 쓰이므로,
  이 안내 문구(와 예/아니요)만 영어 칸에도 한국어로 넣었습니다.
- 일본판도 영어로 표기하는 곳(GAME START·STAGE SELECT 같은 메뉴 제목, 보스 영문 이름, 스태프 롤)은 그대로입니다.

  **스위치 실기와 진행해야 열리는 화면(갤러리·업적·챌린지 결과·후반 이야기)은 아직 확인하지 못했습니다.**
  깨지거나 일본어가 남은 화면, 넘치는 문장은 이슈로 알려 주세요(화면 캡처와 진행 상황을 함께).
- 한글 글꼴은 에스코어 드림(S-Core Dream)으로 그렸습니다.

## 빌드 (참고)

이 저장소에는 번역 원고(`tr/*.json`, 라벨 → 한국어)와 빌드 도구만 있습니다. 원문은 들어 있지 않습니다.

```
python tools/build.py            # _work/romfs(직접 추출한 RomFS) → build/romfs
python tools/width_check.py 1.08 # 번역 줄 폭 검사
python tools/make_dist.py <버전>
```
- `build.py` 는 원고 대조용 원문 목록 `tr/ref/*.txt`(라벨·일본어·영어, 게임 원문이라 미포함)를 RomFS 의 GMD 에서 만들어 둔 상태를 전제로 합니다.
- NSP 추출(`nsp_split.py`, `nca_romfs.py`)은 별도 NSP 파서(`nsptool`)와 본인 기기의 키 파일이 필요합니다.
- 그림 BC7 인코딩에 `etcpak`, 그 밖에 `numpy`·`Pillow`·`lz4` 를 씁니다.
